# Отчёт о проделанной работе (октябрь 2026)

Классификация ТН ВЭД, проект `clearance`. Составлен 28.10.2026. Ключи и токены в отчёт не входят
(лежат в `/Users/user1/proekt/.env.local`).

## 1. Схема работы

Гибрид: Кими (Moonshot) переводит и обогащает товар (перевод, описание, материал), Яндекс ставит код
ТН ВЭД. Обогащение идёт через `app/ai_client.py` (`AI_PROVIDER`), классификация через
`app/classify_ai.py` (`CLASSIFY_AI_PROVIDER`, по умолчанию yandex). Пайплайн v1 — по умолчанию,
v2 (`app/tnved/v2.py`) включается переменной `TNVED_PIPELINE`.

## 5. Изменения в коде

Коммиты в `origin/main`: `374899c`, `83a8638`. Не закоммичено на момент отчёта: изменения в
`app/tnved/v2.py`, `app/tnved_classifier.py`, `scripts/eval_holdout.py` (п. 5.3–5.4).

1. **Лимит запроса Кими в обогащении** (`app/enrich.py`, коммит `83a8638`). Moonshot обрывает
   соединение при запросе больше ~11 КБ (проходят ≤11 028 байт, падают ≥11 510). Раньше ошибка гасилась,
   товары оставались без перевода. Теперь бюджет 10 000 байт, батч делится пополам, контекст инвойса
   для Кими компактный (6 названий по 30 символов, шапка 200). Живая проверка: 60/60 товаров, максимум
   9 963 байта. Тест `tests/test_21.py` обновлён.
2. **v2: отказ не обнуляет код** (`app/tnved/v2.py`). При низкой уверенности возвращается
   предполагаемый код с пометкой «проверить» (на Яндексе +5,1 п.п. точного кода). Из 112 таких
   предположений верны 23.
3. **Лимит запроса Кими в классификации v2** (`app/tnved/v2.py`, не закоммичено). Шаг выбора позиции:
   примечания к группам урезаются, пока запрос не уложится в 9 500 байт. Шаг листа: убираются листья с
   конца списка (не меньше 5). Без этого все вызовы падали с обрывом соединения.
4. **Лимит запроса Кими в классификации v1** (`app/tnved_classifier.py`, не закоммичено). Батч делится
   пополам, одиночный товар теряет кандидатов с конца (не меньше 5). После правки максимум 9 475 байт.
5. **`scripts/eval_holdout.py`**: команды `build | prepare | enrich | run | report`, шесть
   конфигураций, флаг `--enriched`; шаг `enrich` теперь вызывает `enrich_items` штатно.
6. Скрипты сбора и подготовки данных в `scripts/`: `build_finetune.py`, `collect_official.py`,
   `expand_dataset.py`, `extract_fsa.py`, `fsa_collect.py`, `verify_synthetic.py`,
   `check_dataset.py`, `split_golden.py`, `upload_dataset.py`.

## 8. Открытые вопросы и следующие шаги

- Прогоны на обогащённом holdout не сделаны (остановлены); при необходимости запуск: `python scripts/eval_holdout.py run v2_ref --enriched --work training/eval_kimi` с `AI_PROVIDER=kimi CLASSIFY_AI_PROVIDER=kimi`.
- Запустить тесты после правок п. 5.3–5.4, затем коммит и push (по команде владельца).
- Дообучение Яндекса — после выхода датасетов из `VALIDATING` (`tune_deferred`, yandexgpt-lite).
- Включение `TNVED_PIPELINE=v2` в проде: +14–19 п.п., меняет поведение, без команды не включалось.
- Замер на сырых инвойсных названиях; рост recall кандидатов позиции и выбора листа (ошибки листа и
  позиции остаются главными источниками промахов).
- Переключение классификации на Кими в проде — решение владельца: код готов (`CLASSIFY_AI_PROVIDER=kimi`),
  но цифры на Кими получены на небольшой выборке.
