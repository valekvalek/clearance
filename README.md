# InvixAI — полный бэкап приложения

Снят 2026-09-24 с боевого сервера VibeCode (Bitrix24) — на тот момент приложение работало
там. С 11.10.2026 от VibeCode/Bitrix24 отказались полностью: ИИ теперь — Google AI Studio
(Gemini), хостинг — свой сервер. Исторические упоминания VibeCode ниже (URL, раздел
«Развёртывание») относятся только к этому архиву как он был снят, а не к текущему состоянию.

| | |
|---|---|
| Приложение | invix-invoice (InvixAI — обработка китайских инвойсов) |
| URL на момент снятия | https://app-c2dfc305f388.vibecode.bitrix24.tech (не актуален) |
| Рантайм | Python 3.11, запуск `python app.py`, порт из `PORT` (по умолчанию 8000) |

## Что внутри

- `app/` — код приложения (изначально снят с сервера `/opt/app`, с тех пор доработан — см. `docs/ПЛАН_ДОРАБОТКИ.md`): FastAPI `app.py`, `jobs.py`, `auth.py`, `activity.py`, `readers.py`/`images.py`/`extract.py`/`enrich.py`/`export.py` (конвейер обработки инвойса), `sourcing.py`, `gemini.py` (клиент Google AI Studio), `currency.py`, `uploads.py`, `guards.py`, `report.py`, `static/`, `requirements.txt`, `Dockerfile`.
- `data/` — постоянный том `/data` целиком, как он был снят с сервера 24.09.2026:
  - `users.json` — учётные записи (пароли хранятся хэшами pbkdf2);
  - `secret.key` — ключ подписи сессионных кук;
  - `stats.json`, `activity/*.jsonl` — статистика и история действий пользователей;
  - `results/<пользователь>/` — последние 10 результатов обработки (xlsx) на каждого пользователя;
  - `.reset_token` — маркер одноразового сброса админа.

  С доработкой «SQLite вместо JSON» (см. `docs/ПЛАН_ДОРАБОТКИ.md`, шаг 3.5) код сам при
  первом запуске на этом томе переносит `users.json`/`sessions.json`/`stats.json`/
  `activity/*.jsonl` в один файл `data/app.db` и переименовывает исходники в `*.migrated`
  (не удаляет). `secret.key`, `.reset_token`, `results/` — без изменений.
- `meta/` — служебное: `env.txt` (переменные окружения сервиса), `pip_freeze.txt` (точные версии пакетов), `python_version.txt`, `start_cmd.txt`, `listing.txt` (листинг файлов на момент снятия).

## Ключ Gemini — ставится свой

Распознавание и перевод инвойсов идут через Google AI Studio (Gemini, модель задаётся
переменной `AI_MODEL`, по умолчанию `gemini-2.5-flash`), поэтому для работы нужен **свой**
ключ из [aistudio.google.com/apikey](https://aistudio.google.com/apikey) в переменной
`GEMINI_API_KEY`.

Без ключа сервис запускается, вход и история результатов работают, а обработка файла сразу завершается сообщением «Не задан ключ Gemini (GEMINI_API_KEY)».

## ⚠ Чувствительные данные

`meta/env.txt` содержит пароль админа и токен сброса. Также чувствительны `data/users.json` (хэши паролей) и `data/secret.key` — а после первого запуска (см. выше) ещё и `data/app.db`, куда переехали хэши паролей. Передавайте архив по защищённому каналу, а после разворачивания смените пароль админа.

## Запуск локально или на своём сервере

Нужен **Python 3.11**: на нём работает прод, и на нём проверен локальный запуск. На более новых версиях зафиксированные в `requirements.txt` пакеты (Pillow, PyMuPDF) могут не установиться.

Переменные окружения (ключ ИИ, том данных и т.п.) проще всего задать файлом `app/.env` —
он подхватывается автоматически при старте, экспортировать переменные руками не нужно.
Скопируйте шаблон и впишите значения:

```bash
cd app
cp .env.example .env    # уже есть готовый app/.env с местом под ключ — можно править его
# откройте app/.env в любом редакторе и впишите GEMINI_API_KEY (и при первом запуске — ADMIN_PASSWORD)
```

`.venv` не переносится между ОС (скомпилированные бинарники разные — venv,
созданный на macOS, не запустится на Windows, и наоборот), поэтому у каждой ОС
своя папка окружения: `.venv-win` на Windows, `.venv-mac` на macOS. Обе
игнорируются в `.gitignore`.

Windows (PowerShell/cmd):
```powershell
python -m venv ..\.venv-win
..\.venv-win\Scripts\activate
pip install -r requirements.txt
python app.py                    # открыть http://localhost:8000
```

macOS:
```bash
python3 -m venv ../.venv-mac
source ../.venv-mac/bin/activate
pip install -r requirements.txt
python app.py                    # открыть http://localhost:8000
```

`app/.env` — секрет (ключ ИИ, пароль админа), не выкладывайте его публично; в Docker-образ он
не попадает (см. `.dockerignore`). Все переменные и их назначение — см. комментарии в
`app/.env.example`. Переменная, уже заданная в окружении (например, через `-e` в Docker),
имеет приоритет над `.env` и не перезаписывается.

На Windows переменные можно по-прежнему задавать через `set ИМЯ=значение` (cmd) или
`$env:ИМЯ="значение"` (PowerShell) вместо `.env` — `.env` лишь избавляет от необходимости
делать это при каждом запуске.

Войти можно под любой учёткой из архива с её прежним паролем, в том числе под админом
`invixadmin` (пароль в `meta/env.txt`). `ADMIN_USER` / `ADMIN_PASSWORD` нужны, только если
запускать с пустой базой: тогда из них создаётся первый админ.

Через Docker: `docker build -t invix app/`, затем запуск с томом
`-v /путь/к/data:/data -p 8000:8000 -e GEMINI_API_KEY=…` (или смонтировать `.env` в контейнер
отдельным томом, раз он не попадает в образ).

Необязательные переменные: `AI_MODEL`, `EXTRACT_MODEL` (модели Gemini, по умолчанию
`gemini-3.8-flash` — поиск в интернете через встроенный Google Search grounding, платный,
по умолчанию выключен галочкой в интерфейсе), `GEMINI_MODEL_FALLBACKS` (запасные модели через
запятую — если основная упёрлась в лимит/квоту, снята с поддержки или перегружена, код сам
переключается на следующую из списка, по умолчанию
`gemini-flash-latest,gemini-3.1-flash-lite,gemini-2.5-flash`), `OXYLABS_USER` / `OXYLABS_PASS`
(закупка с 1688).

## Развёртывание

VibeCode/Bitrix24 больше не используется — сервис разворачивается на своём сервере. Через
Docker (см. выше) или напрямую: Python 3.11, `pip install -r requirements.txt`, переменные
окружения через `.env` или окружение процесса, `python app.py`. Нужен постоянный том под
`DATA_DIR` и исходящий доступ к `generativelanguage.googleapis.com` (Gemini) и `www.cbr.ru`
(курс ЦБ).
