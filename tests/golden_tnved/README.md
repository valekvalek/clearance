# Эталонный набор ТН ВЭД (Фаза 1)

Сюда складываются подтверждённые примеры «товар → код ТН ВЭД» для
`tnved/evaluate.py` (метрики классификатора, Фаза 1 плана).

## Файл

`golden_tnved.csv` — единственный файл, который читает `evaluate.py`.
Колонки:

| Колонка | Обязательна | Смысл |
|---|---|---|
| `name` | да | Название товара (как в инвойсе) |
| `description` | нет | Описание/доп. контекст, если есть |
| `material` | нет | Материал, если известен |
| `expected_code` | да | Ожидаемый 10-значный код ТН ВЭД |
| `confirmation_source` | да | Откуда взят код (декларация №…, брокер, ГТД, и т.п. — конкретно, не "вручную") |
| `status` | да | `подтверждён` — код реально подтверждён (декларация/эксперт); `кандидат` — вероятно верный, но без строгого подтверждения |

Только строки со `status=подтверждён` считаются в метриках точности
(`tnved/evaluate.py`). `кандидат` — задел на будущее, в расчёт пока не идёт.

## Как добавлять

- Правьте `golden_tnved.csv` напрямую (Excel/LibreOffice/текстовый редактор) —
  добавляйте строки в конец, кодировка UTF-8, разделитель `,`.
- Если сид приходит файлом (xlsx с подтверждёнными декларациями и т.п.) —
  кладите рядом с CSV (например `source_2026-10.xlsx`) как исходник, из
  которого строки перенесены в CSV — так видно, откуда взялась запись.
- Не выдумывать `expected_code` и `confirmation_source` — если источник
  неизвестен, строка не подтверждённая, ставьте `status=кандидат`.
